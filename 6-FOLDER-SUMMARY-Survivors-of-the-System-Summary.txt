THE PATTERN
════════════════════════════════════════════════════════════════════════

Person enters system vulnerable -> system documents them as the problem
-> that documentation used against them in every future encounter ->
each new institution trusts the prior institution's record -> original
error compounds into undeniable pattern -> person loses what the system
decided they don't deserve.

Ricky knows this from inside. He is trying to interrupt it for others
before it finishes running.
