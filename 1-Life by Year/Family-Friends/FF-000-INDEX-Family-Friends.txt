FAMILY AND FRIENDS - INDEX
Folder: 1-Life by Year / Family-Friends, in The Memory Ark
(memory-ark.com - the GitHub archive: github.com/Thestebbman/Memory_Ark)

Last updated: November 1, 2026

This is the map of the people files. One file per person, plain text.
Each character file points to everything the Ark holds about that
person - the year files their stories live in, and the links outside
the Ark (an old Facebook, an obituary page) - and leaves dated space
for anyone who knew them to add a story.

To make a new character file, copy FF-000-TEMPLATE-character-file.txt,
rename it for the person, and fill it in. Where the record does not say
something, the file says so and leaves the space open. Nothing is
invented to fill a blank.

----------------------------------------------------------------

HOW TO FILE A NOTE ABOUT A PERSON
Talk first. Ricky tells it, or a note gets dropped in any size, and the
note is filed here - dated, in the person's file, and in any other
person's file the same story belongs in. One story can live in several
files at once, cross-referenced, with the same date. That is the whole
method; the app being built exists to make this faster, not different.
